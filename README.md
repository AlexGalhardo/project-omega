# Project Omega

A planned original top-down arena-survival roguelite and a reusable 2D layer over Bevy. `Project Omega` is the repository name; the game's identity is undecided.

Current checkpoint: **Stage 1 research delivered; awaiting the first Stage 2 owner decision.** Start with the [research summary](docs/research/00-summary.md), then the [open questions](docs/research/open-questions.md). Sources, revisions and evidence limits are recorded in the [source ledger](docs/research/sources.md).

This repository currently contains research and the [IP policy](docs/legal/ip-policy.md). It has no game implementation, Rust workspace, runnable build or executed performance baseline. Bevy 0.20.0 is the researched baseline, not an installed dependency. The provisional strategy is upstream Bevy with own plugins; the owner has not approved that decision yet.

All repository artifacts are written in English. Conversation with the owner is in Brazilian Portuguese. Product decisions and stage approvals must be recorded in the repository as planning progresses. Implementation begins only after the architecture/specification and roadmap gates are approved; earlier experiments require explicit authorization. See the research summary for the planning sequence and current limits.
